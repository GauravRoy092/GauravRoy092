## 👨‍💻 About Me

I'm an Analyst with a deep passion for uncovering stories hidden in data. I turn raw, messy datasets into clear insights that help businesses make smarter decisions.

💡 **What I do:**
- Transform complex data into compelling narratives that drive strategy
- Build intuitive dashboards and reports that make insights easy to understand
- Write efficient SQL queries for database management and analysis
- Use Python for robust data analysis and predictive modeling

🛠️ **Tools I work with:**
- Advanced Excel & Data Visualization
- AI in Excel for predictive analytics
- SQL for efficient data management
- Python (Pandas, NumPy, Matplotlib, Seaborn)
